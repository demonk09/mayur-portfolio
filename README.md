# Mayur Kamble — Portfolio

Next.js portfolio and installable PWA for an Automotive HIL & Test Automation Engineer.

## Stack
- Next.js App Router
- React + TypeScript
- Lucide React
- Responsive CSS
- PWA manifest
- Vercel-ready

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Import `demonk09/mayur-portfolio` into Vercel. Vercel will detect Next.js automatically.
